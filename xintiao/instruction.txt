# Heartbeat Ripple Light ❤️

基于 ESP32 的**实时心跳涟漪灯与波形显示**，使用 MAX30102 心率传感器检测脉搏，驱动内外双环 WS2812B LED 以白光涟漪动画模拟心脏搏动，同时 OLED 屏幕实时绘制 PPG 光电容积描记波形。

---

## 功能简介

- 🫀 **手指触摸检测**：将指尖轻放在 MAX30102 传感器上，系统自动识别并开始监测。
- 💡 **双环涟漪心跳灯**：每检测到一次心跳，内圈 8 颗 LED 先亮，随后外圈 16 颗 LED 向外扩散，模拟心脏泵血效果。
- 📊 **OLED 实时波形**：0.96 寸 OLED 显示屏绘制动态 PPG 波形，并显示实时心率 BPM。
- ⚙️ **高灵敏度算法**：采用成熟的心跳检测算法（heartRate），抗干扰能力强，手指稳定贴合即可准确响应。
- 🔧 **完全可定制**：LED 颜色、动画速度、传感器电流等参数均可通过代码修改。

---

## 工作原理简介

- **MAX30102** 芯片集成红光/红外 LED 和光电探测器，向指尖发出光线并接收反射光。心脏搏动引起毛细血管血容量周期性变化，导致光吸收强度随之波动。
- 传感器通过 I²C 接口输出原始红外 PPG 信号，ESP32 读取后经过滤波和 `checkForBeat()` 峰值检测算法识别每一次心跳。
- 检测到心跳后，触发双环 WS2812B 的涟漪动画：内圈（代表心脏收缩）先全亮白光，外圈逐渐点亮（代表血液泵出），最后整体渐暗。
- OLED 屏幕绘制最近 100 个采样点的波形曲线，并显示平均心率。

## 所需元件

| 名称 | 规格/型号 | 数量 | 用途 |
|------|-----------|------|------|
| 微控制器 | **ESP32 Dev Module** (ESP32-WROOM) | 1 | 主控 |
| 心率传感器 | **MAX30102** (I²C 模块) | 1 | 指尖脉搏检测 |
| WS2812B 内圈灯环 | 8 位 (外径约 37mm) | 1 | 内心脏收缩动画 |
| WS2812B 外圈灯环 | 16 位 (外径约 62mm) | 1 | 外圈血液泵出动画 |
| OLED 显示屏 | **0.96 寸 SSD1306 I²C (4 针)** | 1 | 波形与心率显示 |
| 电解电容 | 1000μF / 16V | 1 | 灯环电源滤波 |
| 电阻 (可选) | 300~500Ω | 2 | 保护 WS2812B 数据引脚 |
| 面包板 + 跳线 | 若干 | | 连接电路 |
| Micro USB 数据线 | | 1 | 供电与烧录 |

> 注：内圈和外圈灯环需单独购买（只有 3 个引脚，无 DOUT），因此使用两个独立 GPIO 控制。

## 接线图与引脚说明

### I²C 总线 (共用)
| ESP32 引脚 | 连接至 |
|------------|--------|
| **GPIO21** (SDA) | MAX30102 SDA ↔ OLED SDA |
| **GPIO22** (SCL) | MAX30102 SCL ↔ OLED SCL |

### MAX30102
| 引脚 | 连接至 |
|------|--------|
| VIN | ESP32 **3.3V** (⛔ 不可接 5V) |
| GND | ESP32 GND |

### OLED (0.96" SSD1306)
| 引脚 | 连接至 |
|------|--------|
| VCC | ESP32 **3.3V** |
| GND | ESP32 GND |

### 内圈灯环 (8 LED)
| 引脚 | 连接至 |
|------|--------|
| VCC | 外圈 VCC → **5V (ESP32 VIN)** |
| GND | 外圈 GND → ESP32 GND |
| DIN | ESP32 **GPIO4** (可串 470Ω 电阻) |

### 外圈灯环 (16 LED)
| 引脚 | 连接至 |
|------|--------|
| VCC | 内圈 VCC → **5V (ESP32 VIN)** |
| GND | 内圈 GND → ESP32 GND |
| DIN | ESP32 **GPIO5** (可串 470Ω 电阻) |

### 电源滤波
- 1000μF 电容正极接 **5V (VIN)**，负极接 **GND**，紧贴灯环电源端。

> ⚠️ **重要提示**：  
> - 灯环由 5V 供电（ESP32 VIN 来自 USB），MAX30102 和 OLED 必须用 3.3V。  
> - 24 颗 LED 全白时电流较大，代码中已将亮度限制为 60，若需更高亮度请使用外置 5V/2A 电源并共地。  
> - 数据脚可串联 470Ω 电阻以保护 IO 口，一般情况下不接也能工作。

## 软件开发环境与库依赖

- **IDE**: Visual Studio 2022 + **Visual Micro** 插件  
  （或 Arduino IDE / PlatformIO 均可）
- **开发板配置**: ESP32 Dev Module
- **所需库** (通过库管理器安装):
  - `SparkFun MAX3010x Pulse and Proximity Sensor Library`
  - `Adafruit NeoPixel`
  - `Adafruit SSD1306`
  - `Adafruit GFX Library`

> 心率算法文件 `heartRate.h` / `heartRate.cpp` 位于 SparkFun 库的 `src` 文件夹中，已被项目引用，**无需手动复制**。

---

## 安装与上传

1. 按上述接线图连接所有硬件。
2. 在 VS 2022 中创建 vMicro Arduino 项目，选择板子为 **ESP32 Dev Module**。
3. 安装所需库 (`vMicro → Add Library`)。
4. 将本项目中的 `.ino` 文件（或完整源码）粘贴到项目中。
5. 连接 ESP32 USB 线，在 vMicro 工具栏选择正确 COM 端口，点击 **Upload**。
6. 上传完成后打开**串口监视器** (115200 波特率)，应看到 `MAX30102 ready.` 及 `Place finger on sensor.`。
7. 将食指指尖轻轻盖在 MAX30102 模块的玻璃窗口上，保持稳定。数秒后串口输出 `Warm-up done.` 并开始打印 `BPM: xx`。
8. 此时灯环开始以白光涟漪闪动，OLED 显示实时波形与心率。

## 使用说明

- **手指放置**：指腹自然覆盖传感器窗口，轻微贴合即可，**不要用力按压**或移动。
- **效果观察**：内圈先亮 → 外圈渐亮 → 整体渐暗，循环往复，应与心跳同频。
- **波形显示**：屏幕上部显示心率，下部显示流动的红外信号波形。无手指时波形平坦。
- **调试输出**：串口每 500ms 打印 IR 原始值、信号幅度和 BPM，可用于判断传感器状态。

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 串口显示 `MAX30102 not found` | I²C 接线错误或模块未供电 | 检查 SDA→GPIO21, SCL→GPIO22, VIN→3.3V, GND |
| 灯不亮，BPM 始终为 0 | 手指阈值过高或传感器未检测到手指 | 检查串口 IR 值：若低于 `FINGER_THRESHOLD` (默认 50000)，降低阈值或稍用力贴紧手指 |
| 灯光乱闪或与心跳不同步 | 手指移动或信号噪声大 | 保持手指稳定，可适当降低 LED 电流（修改 `initMAX30102` 中的 `0x1F` 到 `0x0A`） |
| OLED 波形成一条直线 | 显示缩放不对或数据未更新 | 确认 `waveBuf` 是否存入数据；调整代码中波形幅度强制扩展逻辑 |
| 灯环颜色异常或不亮 | WS2812 数据脚接触不良或供电不足 | 检查 GPIO4/GPIO5，确保 5V 供电；尝试串联 470Ω 电阻 |

## 代码结构简析

- `initMAX30102()`：直接通过 I²C 寄存器配置传感器（SpO2 模式、采样率 400Hz、LED 电流 0x1F）。
- `readFIFO()`：从 FIFO 读取原始红外值（18 位）。
- `loop()` 中调用 `checkForBeat(ir)` 识别心跳，更新 BPM，触发 `beatFlag`。
- `animate()`：非阻塞式双环白光涟漪动画。
- `drawWave()`：在 OLED 上绘制最近 100 个采样点的波形，并自动缩放纵轴。

---

## 个性化定制

- **修改灯色**：将 `animate()` 中的 `inner.Color(b,b,b)` 改为 `inner.Color(b, 0, 0)` 即红光。
- **调整灵敏度**：修改 `FINGER_THRESHOLD` 和 `initMAX30102()` 中 LED 电流值。
- **改变动画速度**：调整 `animDur` 变量（毫秒）。
- **添加血氧显示**：读取红光值并集成 SpO2 算法。
