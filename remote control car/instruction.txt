## 手机 Wi-Fi 遥控小车制作使用说明（ESP32-C3 + TB6612）

### 一、所需硬件清单

- 合宙 ESP32-C3 开发板（带 CH343 串口芯片）
- TB6612FNG 电机驱动模块
- 18650 锂电池 1 节（3.7V–4.2V）
- 18650 电池盒（带导线）
- 直流电机 2 个（通常带轮子，可拆自旧玩具车）
- 小车底盘（能固定电机和电路板）
- 杜邦线若干（公对母、母对母）
- 电解电容 100μF–470μF（可选，用于减少电机干扰）
- 开关（可选，方便通断总电源）

### 二、接线方法

**1. 信号线连接（ESP32-C3 → TB6612）**

- GPIO 4 接 AIN1
- GPIO 5 接 AIN2
- GPIO 6 接 PWMA
- GPIO 7 接 BIN1
- GPIO 8 接 BIN2
- GPIO 10 接 PWMB
- GPIO 9 接 STBY
- 3.3V 接 VCC（给 TB6612 逻辑电路供电）
- GND 接 GND（控制电路共地）

**2. 电机连接**

- TB6612 的 AO1、AO2 接左电机的两根线
- TB6612 的 BO1、BO2 接右电机的两根线

**3. 供电连接（单节 18650）**

- 电池正极同时接到 TB6612 的 VM 和 ESP32 的 5V 引脚（注意是 5V 引脚，不是 3.3V）
- 电池负极同时接到 TB6612 的 GND 和 ESP32 的 GND
- 务必保证 ESP32、TB6612、电池三者的 GND 全部连通

> **注意**：单节 18650 满电 4.2V，需接入 ESP32 的 5V 引脚，利用板载 LDO 降压至 3.3V。严禁接入 3.3V 引脚。若使用两节 18650 串联（7.4V–8.4V），则必须外接 5V 降压模块给 ESP32 供电，电池直接给 VM 供电。

**4. 防干扰措施（推荐）**

- 在电池正负极之间并联一个 100μF–470μF 的电解电容，注意正负极不要接反，可有效防止电机启动瞬间导致 ESP32 重启。

### 三、程序烧录

1. 在电脑上使用 Visual Micro 或 Arduino IDE 打开项目代码。
2. 开发板型号选择“AirM2M CORE ESP32C3”或“ESP32C3 Dev Module”。
3. 设置 Flash Mode 为 DIO，Upload Speed 设为 115200。
4. 用 USB 数据线连接 ESP32-C3 到电脑，编译并上传程序。如上传失败，可按住板子上的 BOOT 键不放，再按一下 RST 键后松开 BOOT，进入下载模式后重试。
5. 上传成功后，断开 USB 线，接上电池供电。

### 四、手机遥控方法

1. 给 ESP32 和 TB6612 接通电池电源，等待几秒。
2. 在手机 Wi‑Fi 列表中搜索并连接热点“MY_ESP32_C3”，密码为“12345678”。
3. 打开手机浏览器，在地址栏输入“192.168.4.1”并访问。
4. 页面将显示方向盘遥控界面，包含“▲ 前”“▼ 后”“◀ 左”“▶ 右”“■ 停”以及“+”“-”速度调节按钮。点击按钮即可实时遥控小车，无需页面跳转。

### 五、常见问题与解决方法

**小车没有反应，或 ESP32 指示灯不亮**
- 检查电池是否有电，电压是否高于 3.6V。
- 检查所有 GND 是否可靠共地。
- 检查电池正极是否接至 ESP32 的 5V 引脚（不可接 3.3V）。
- 若使用开关，确认开关已打开。

**前进/后退方向相反**
- 将左、右电机的两根线分别对调（即 AO1 与 AO2 交换，BO1 与 BO2 交换），或者整体对调左右两个电机。

**左转/右转方向相反**
- 将左右电机整体对调：AO1、AO2 改接右电机，BO1、BO2 改接左电机。该操作不会影响前进/后退方向。

**小车行进中突然停止或重启**
- 极可能是电机启动时瞬间拉低电池电压，导致 ESP32 掉电重启。可在电池正负极并联一个 100μF–470μF 的电解电容，或更换内阻更小的电池。

**手机搜不到 Wi‑Fi 热点**
- 按一下 ESP32 板子上的 RST 键重新启动程序。
- 检查供电是否稳定，确保电池电压足够。

**速度调节无效**
- 确认程序已烧录正确版本，该功能需配合“refreshMotion”逻辑，烧录本说明对应代码即可支持行进中调速。

**如果想使用两节 18650 获得更高速度**
- 两节电池串联（7.4V–8.4V）只能直接给 TB6612 的 VM 供电；ESP32 必须通过额外的 5V 降压模块供电，**严禁**将两串电池直接接入 ESP32 的 5V 引脚。同时需要从 ESP32 的 3.3V 引脚给 TB6612 的 VCC 供电。

以上即为一套完整的 ESP32-C3 手机遥控小车制作指南。按照说明接好线、烧录程序，即可使用手机在 Wi‑Fi 范围内轻松控制小车。
